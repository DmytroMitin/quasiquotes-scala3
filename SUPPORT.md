# Support

This project is experimental and currently has no service-level, response-time,
or long-term maintenance commitment.

Before opening a non-sensitive issue, include the JDK, sbt, Scala compiler
version, module (`core` or `frontend`), a minimal reproduction, and the complete
structured error without credentials or private source. Use the exact matching
frontend artifact for the compiler line under test.

The source checkout is the supported evaluation path until artifacts are
published remotely. `dottyInternal` is unpublished and is not an ordinary user
support surface. See [Compatibility](docs/COMPATIBILITY.md) and
[Supported syntax and limitations](docs/SUPPORTED_SYNTAX_AND_LIMITATIONS.md)
before reporting unsupported syntax as a defect.

Security-sensitive material must not be posted publicly; see
[Security policy](SECURITY.md). No private reporting channel is currently
offered or promised; a channel may be added later.
